Tina Change View

Workspace 决定认证 Authority

DSH Host 只承载工具；operator 配置的 Workspace public origin 才接收认证请求，模型不能把 Host 的 3080 端口当成 Authority。

Scope / Non-goals

只修改 dsh-univer-work 的认证入口、Cordis bundle patch、测试和文档。保持单 origin、两阶段 handoff、credential secrecy 与现有 Workspace Server contract；不增加 Settings UI 或 account selector。

Decisions

  • workspace_auth_start({}) 使用 Host-owned origin。
  • bundle patch 从 UNIVER_WORKSPACE_ORIGIN 注入。
  • 缺失或非法配置在 HTTP 前返回 workspace-origin-invalid。

Risk / Verification

配置错误会阻止 start。回归测试固定 DSH Host 3080、Workspace 3020，并断言认证请求只到 3020；其他 credential、cancellation 与 package 行为保持原有 gate。
