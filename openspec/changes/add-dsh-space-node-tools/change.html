Tina Change View · add-dsh-space-node-tools

七个稳定 tools 复用一条 Space/Node Core 路径

四个 Node mutation 先用同一纯 validator 拒绝非法参数，再请求一次性 approval，body 随后复验；DSH 已记录的 caller arguments 不在插件可抹除范围内。

Scope / Non-goals

  • 只交付 Space list/browse/find 与 Node create/rename/move/trash。
  • Host-only、HTTP-only；复用 Change 2 的认证与 owner。
  • 不加入 Worktree/Unit/open、文件、runtime、Skills、Web 或 Jobs。

Decisions

  • 七个 operation-specific names，closed root 与 exact-key runtime gate 同时生效。
  • 四个 mutation 在 tools/pre-execute 中先纯校验，合法才 ask；body 再验。
  • 自指 move 在 resolver 前拒绝；后代与跨 Space 仍由 Server 判断。

Risks / Impact

  • caller-aborted late success 由 DSH 记为 ABORTED；随后 browse/find 核对且不自动重放。
  • tool-owned workspace-result-unknown 保留；owner-only dispose 可返回 Core 已确认结果。
  • 错误只透传冻结 code allowlist 与 exact safe detail。
  • Native call 与 Code Mode start/settled arguments 可保留原参数；approval、failure/result、plugin context/log 不复制。
  • 影响 DSH app 与 Client Core；Server、CLI contract 和 SDK baseline 不变。
