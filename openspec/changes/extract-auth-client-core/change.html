Tina Change View · extract-auth-client-core

提取认证协议，保留 CLI 凭据所有权

Client Core 统一调用和校验 Workspace 认证协议；CLI Client Shell 继续管理 Config、Session 文件、pending authorization 与用户交互。

Scope / Non-goals

提取 password login、browser approval、whoami 与 remote logout 协议。CLI Config、Session schema、文件权限、pending 持久化、密码输入和 Commander surface 不移动。

Decisions

复用 Change 1 的 private packages/client-core 与 WorkspaceHttp。Core 使用显式 origin/credential 的 protocol functions；不增加 credential-store interface、factory 或新 package。

Risks / Impact

Cookie 只返回 CLI facade，不进入命令输出。remote logout 结果未知时，CLI 仍清除本地 Session 并报告原错误。实现只写入 univer-workspace。
