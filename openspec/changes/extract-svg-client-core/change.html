SVG 成为最后一条 Client Core vertical slice

复用既有 compiler、browser render 与 Slide execution，把 CLI 缩成命令外壳，并用一次完整 package checkpoint 结束十段提取。

Scope / Non-goals

  • 只迁移 SVG compile、text measure、page wrap 与 apply。
  • 不改 compiler、CLI 参数、输出或 commit 行为。
  • 不创建 DSH app、第二个 package 或 filesystem abstraction。

Decisions

  • Core 读取本机 SVG 与相对 asset；`--out` 留在 Shell。
  • 真实测量惰性启动并关闭 browser；估算只在显式选择时使用。
  • 同一编译结果驱动 raw、page 与一次 Slide execution。

Risks / Impact

  • Change 6/9 seam 缺失时停止，不复制 owner。
  • CLI 继续交付 render page、worker、Skills、Puppeteer 与 native bindings。
  • 最终 gate 覆盖 source、package verify 与 tarball smoke。
