Tina Change View · add-dsh-office-exchange-tools

把 Office 文件交换接到 DSH 原生工具

两个 Host-only tools 复用既有 local file gate、Workspace Client Core 与 worker runtime：import 有界收集 source stream 的实际 bytes 后创建新 Worktree-local Unit，export 只在 runtime 确认 exact revision 后原子写入 Session cwd。

Scope / Non-goals

  • Import：XLS/XLSX、DOC/DOCX、PPT 系列，创建新 Worktree-local Unit。
  • Export：Worktree head 到 XLSX/DOCX/PPTX。
  • 不支持 CSV、Board、替换既有 Unit、Trunk 或 remote FS。

Decisions

  • 两个 closed tools；参数与 512 KiB budget 在 ask 前验证。
  • Import 复用 Change 5 path-based stream，并以有界 bytes 调用 importBuffer。
  • Export 要求 Change 6 runtime 确认 exact revision，head 推进即失败。
  • 50 MiB / depth 64；export 默认 no-clobber，`force: true` 才原子替换。

Risks / Impact

  • Native conversion 不可中断：等待完成，再停止后续 side effect。
  • Source identity 继承 Change 5：无 cross-process openat fence。
  • Create dispatch 后所有未确认结果：检查 Unit identity，不重放。
  • Tarball 必须携带 worker 与 exact exchange binding。
