Tina Change View · verify-dsh-workspace-cli-parity

用一个安装态 gate 证明 CLI outcome parity

冻结完整 CLI surface、十二个前置 owner 与 DSH rc.2 合同，统一驱动 catalog、真实 policy probe、行为和 package 验收；任何缺口都回到原 owner，最终 Change 不补业务能力。

Scope / Non-goals

只新增 parity manifest、verification gates 与责任文档。完整分类 browser setup、resource cache、password login、viewer override 等 shell mechanics，但不为它们制造模型 tools。

Decisions

  • 按 outcome 比较两个 Client Shell，不要求命令形状一致。
  • 两个 Client Shell 仅通过仓库内 private Client Core exports 共享能力。
  • 同一 manifest 驱动 catalog、行为、package 和 README 检查。
  • 固定上限：16 MiB packed、64 MiB unpacked、256 entries。

Risks / Impact

只伪造 loopback remote authority/approval/credential endpoints；真实 local filesystem、worker、native binding 与 browser 暴露安装差异。dispose 清理 volatile runtime，但保留有效持久 grant。
