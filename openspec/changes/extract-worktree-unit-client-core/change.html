Tina Change View

提取 Worktree 与 Worktree Unit Client Core

把草稿状态机、Unit membership 与 review URL 规则移入同一个 private Client Core，同时让 Workspace CLI 的命令、Session、输出和可靠性合同保持不变。

Scope / Non-goals

  • 只迁移 Worktree、Worktree Unit 与 review URL vertical slice。
  • 不修改 Server contract、产品状态机、CLI command surface 或 Session。
  • 依赖 Space/Node 与 Auth 两个前序 Changes。

Decisions

  • 扩展同一个 private packages/client-core。
  • Core 只接收惰性 HTTP/origin functions，不导入 WorkspaceAuth。
  • CLI 保留 Commander、配置默认值与输出。

Risks / Impact

  • 可靠性算法原样迁移，并用 owner tests 固定校验顺序。
  • exchange 与 Typst 只切换共享类型 imports。
  • 真实 tarball smoke 验证自包含交付。
