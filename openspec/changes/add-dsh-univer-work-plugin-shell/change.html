Tina Change View

dsh-univer-work Host-only 插件壳

先把预构建 tarball 到 Cordis fiber 的安装与生命周期链路跑通，再在后续 Changes 中接入认证、tools、Skills 和 Workspace runtime。

Scope / Non-goals

  • 一个 private、Host-only、local profile package。
  • 只交付 manifest、patch、Host entry 和安装态 smoke。
  • 认证、Client Core、tools、Skills、Jobs 与 Web Client 全部后移。

Decisions

  • 使用现有 TypeScript/Vitest，不新增构建框架。
  • Host entry 保持 inert，不预留业务服务或配置。
  • 真实 tarball add/dump/start 是验收路径，源码 overlay 不替代它。

Risks / Impact

  • 精确对齐 DSH 0.1.1-rc.2，升级时重跑安装 smoke。
  • 临时 DSH_HOME 隔离 profile，并以 deadline 约束清理。
  • 新增 application 与领域文档；Server、Browser、CLI 和 SDK baseline 不变。
