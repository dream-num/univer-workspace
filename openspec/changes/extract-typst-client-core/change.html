Tina Change View · Change 8

把 Typst-to-Doc workflow 移入 Client Core

CLI 与未来 local DSH Client Shell 复用同一次编译、确定性 Doc materialization 和 Worktree-local Unit create；各自继续拥有命令呈现与可安装 artifact。

Scope / Non-goals

  • 迁移 compile、materialize、apply 三段 workflow。
  • Commander、输出文件、Session 与 daemon 留在 CLI。
  • 不改 bundle schema、compiler、diagnostics 或 Unit create 语义。

Decisions

  • 扩展一个 private packages/client-core。
  • Typst 使用一次性 Doc runtime，不复用 collaboration pool。
  • 直接复用 Worktree-local Unit create，不复制可靠性算法。

Risks / Impact

  • 固定 random 恢复与 runtime dispose 测试。
  • CLI artifact 继续交付平台 native binding。
  • 安装 smoke 必须在 monorepo 外完成真实编译。
