Tina Change View

给 DSH Agent 可审阅的截图与 Slide 布局诊断

DSH Client Shell 通过 private Workspace Client Core exports 组合两个 DSH-native tools；截图经过本地文件 gate，lint 保持只读。

Scope / Non-goals

  • 截图覆盖 Trunk/Worktree 的五类 Unit；lint 只检查 Worktree Slide。
  • PNG 只写 local Session cwd，不返回 bytes、不覆盖既有文件。
  • Chromium 保持 --no-sandbox；部署需受限 OS user/container。

Decisions

  • 两个 outcome-specific tools 只通过 private Core exports 复用 render capability。
  • file-transfer/content 各导出一个 projector；allowlist sets 保持私有。
  • 截图在 approval 两侧重查 file policy、local provider 与 path containment。
  • 完整 metadata 在首 PNG 前过 schema/8 MiB/depth gate；失败写零文件。
  • 取消或晚期失败保留已确认 PNG、固定 partial identity，禁止自动重放。

Risks / Impact

  • tarball 新增 render page；从 runtime 实际安装位置解析 exact Puppeteer versions。
  • 浏览器缺失时明确失败，不隐式下载。
  • approval 只管文件 effect，不提供 browser process isolation。
