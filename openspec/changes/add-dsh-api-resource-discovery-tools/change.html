Tina Change View · add-dsh-api-resource-discovery-tools

按需发现 API 与 SVG 资源

五个 credential-free tools 读取版本匹配的随包数据；只有 SVG export 经过本地文件策略、一次授权与 body 复核后产生原子文件。

Scope / Non-goals

一个 capability、五个 tools。四个查询纯只读；export 仅支持 Host-local Session cwd。不包含 Skills、inline SVG、cache 管理、remote filesystem、Web UI 或 docs server。

Decisions

  • 精确复用已发布 API/resource packages。
  • closed schemas 与固定 fan-out/result budgets。
  • 每次 export 独立 library/adapters；无 shared current-call。
  • 10 MiB 单项失败可继续；32 MiB 累计耗尽终止后续网络。
  • public library 决定 filename；应用内最小 helper 原子发布。

Risks / Impact

重复 export 会重新下载；测得成本需要复用时再增加 cache 合同。取消后保留已确认文件，调用方先检查目录再重试。影响限于 `apps/dsh-univer-work/**` 与 exact discovery dependencies。
