Tina Change View · add-dsh-content-runtime-tools

两个 tools，共用一个可信内容运行时

DSH 通过有界、应用层完整校验的 inspection 和一次批准的 Draft Facade execution 复用 Client Core worker，并在远端 mutation 前拒绝超限 execute value。

Scope / Non-goals

  • 只交付 workspace_content_inspect 与 workspace_content_execute。
  • 不带 Commander selectors、--script、daemon、文件、Office、render 或生成能力。
  • 两个 capabilities，八个 coarse tasks。

Decisions

  • 固定 512 KiB arguments、code、selector/range、cell、canonical JSON 与 nesting 预算。
  • inspection 由应用层校验七个 union 和递归 children；DSH schema 如实使用非递归 projection。
  • credential 更新会关闭旧 runtime generation；下一次调用从当前 grant 重建。

Risks / Impact

  • Facade code 保留既有 worker JavaScript authority，因此每次 execute 都需人类批准。
  • 仅 confirmed body late success 转为 ABORTED；partial / unknown throw 保留原 code。
  • confirmed image upload 后取消会留下 orphan candidate；不补偿删除、重传或 replay。
