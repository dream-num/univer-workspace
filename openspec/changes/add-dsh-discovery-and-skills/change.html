Tina Change View · Change 10

按需发现 API 与资源，渐进加载七份 Skills

同一安装包把五个有界 discovery tools、精确 SDK 数据和七份 DSH-native Skills 对齐；只有 SVG export 进入本地文件审批边界。

Scope / Non-goals

只增加五个 discovery tools 与七个非 core Skills。无 Web、Settings、Jobs、动态 Skill provider、docs server、inline SVG 或 CLI subprocess；不修改 Client Core。

Decisions

  • 四个查询 keyless；仅 export 复用文件 policy、cwd 与一次审批。
  • API 结果不截断，超预算要求缩窄查询。
  • `core` 留在 Change 4；本 Change 显式注册其余七份。

Risks / Impact

tool/Skill/SDK 漂移由同包 catalog 检查阻断；export 对每个派生 SVG 目标做双阶段路径校验。影响集中在 `apps/dsh-univer-work/**` 和其安装态验证。

评审投影来自 proposal.md 与 design.md；Markdown 源文件是权威依据。
