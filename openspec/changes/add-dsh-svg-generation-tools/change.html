Tina Change View · add-dsh-svg-generation-tools

让 DSH Agent 用受约束的本地 SVG 生成 Slide

两个稳定工具覆盖编译、代码输出和 Draft apply；DSH Client Shell 负责策略与生命周期，同仓 private Client Core 继续独占 SVG 编译和 Slide execution workflow。

Scope / Non-goals

首版仅支持 local Host profile。输入是 Session cwd 内的 SVG 与 relative assets；apply 只写 Draft Worktree Slide Unit。不加入 Typst、Office、screenshot、Skills、daemon、Jobs、Web UI 或 remote filesystem。

Decisions

  • compile 与 apply 使用两个独立工具。
  • 代码可 inline 返回；apply 可在一次组合 approval 后先保存同一程序。
  • 两个 Client Shell 只经同仓 private Core exports 共享 workflow。

Risks / Impact

已打开 regular-file identity 的 bounded read 限制路径竞态与内存膨胀。body 观察到的 file-confirmed 失败返回 partial；仅 registry 捕获的 late abort 保持 ABORTED，不伪造 location。
