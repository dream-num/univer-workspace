Tina Change View · 09 / 10

把浏览器截图与 Slide lint 移入 Client Core

一个共享 owner 负责 render Unit、browser runtime、PNG 与 Slide layout lint；Client Shell 继续负责命令、license、浏览器安装和可安装资产布局。

Scope / Non-goals

  • 只迁移 browser screenshot、render Unit 和 Slide layout lint。
  • SVG compile、字体测量与 apply 留给第 10 个 Change。
  • 不增加 browser pool、force overwrite 或 filesystem provider。

Decisions

  • 复用 Changes 4、5、6 的真实 operations，不复制协议。
  • render page source 归 Client Core；各 Client Shell 复制并传入路径。
  • CLI 保留 Commander、browser setup 和 license 解析。

Risks / Impact

CLI artifact 必须继续包含 `dist/render-runtime`、`puppeteer-core` 与 `@puppeteer/browsers`。现有 SVG 字体测量在下一 Change 前仍使用该页面，因此 package gate 同时覆盖这个临时 consumer。
