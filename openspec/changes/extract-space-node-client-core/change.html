Tina Change View · extract-space-node-client-core

先把 Space/Node 从 CLI 外壳中取出来

建立一个 Node-hosted private Client Core，让 Workspace CLI 通过 package exports 复用现有能力，同时保持命令、可靠性和安装产物不变。

Scope / Non-goals

  • 只迁移 errors、HTTP、Space/Node。
  • 认证存储、Commander 与 daemon 留在 CLI。
  • 不创建 DSH app，不支持 Browser，不发布 npm。

Decisions

  • 一个 private package，使用 public named exports。
  • Client Shell 提供惰性 authenticated HTTP。
  • 旧 CLI 路径只保留临时 re-export shim。

Risks / Impact

  • 先构建 Core，避免 stale dist。
  • 单一 error 定义保持 instanceof。
  • 实现只写入 univer-workspace。
本页仅供评审。proposal.md 与 design.md 是权威来源。
