Tina Change View

七份指导与同一 installed tool catalog 一起交付

将 Unit/Topic 知识改写为 DSH-native Skills，打包时核对实际工具名，运行时只借用原生 SkillRegistry 的按需加载与生命周期。

Scope / Non-goals

只新增 `base`、`board`、`cross-unit-formula`、`doc`、`embed`、`sheet`、`slide`。`core` 仍归 Change 4；不做动态下载、filesystem watcher、Web UI 或 discovery tools。

Decisions

  • frontmatter 固定为 `name` 与 `description`，拒绝 `allowed-tools`。
  • 逐 Skill required/forbidden matrix 与 semantic anchors 同时检查。
  • 七份先整体验证，再分别注册；沿用 model/user 默认 invocation。
  • 其余工具引用以十个 accepted owners 的真实 installed catalog 为准。

Risks / Impact

CLI 与 DSH 文本可能漂移，matrix、Facade anchors 与真实 catalog 共同阻断错误 package。安装 smoke 隔离空 project/DSH/AGENTS roots，并允许默认 provider 查询这些空根；plugin 不新增 provider、root 或 watcher。Client Shell 与 private Core 的职责以仓内 Workspace CONTEXT 和 ADR 0007 为准。
