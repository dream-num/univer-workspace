Tina Change View · add-dsh-worktree-unit-tools

把发现到的 Resource 送进可评审的 Worktree

十二个稳定 tools 与一个静态 core Skill 复用同一 Host owner 和 Client Core，在不复制 CLI 或 Workspace 协议的前提下交付任务准备、rework 与 review handoff。

Scope / Non-goals

  • 覆盖 Worktree、Unit 与 review URL outcome；不复制 Commander tree。
  • 首个 core Skill 只引用 Changes 2–4 已存在的 tools。
  • 文件、content runtime、Office、render、discovery 与其余 Skills 后移。

Decisions

  • merge、discard 等操作各用独立 tool；不增加 generic lifecycle router。
  • 八个 mutation 先复用纯 validator，成功后才请求一次性 approval，body 再验。
  • review URL 固定使用本次 authenticated grant 的 origin。
  • Skill 由 Host 显式注册，不增加 provider、watcher 或新依赖。

Risks / Impact

  • 取消后的远程写入可能未知：停止新 attempt，保留 result-unknown，先 get/list 核对。
  • 非法参数只留在 DSH-owned Native 一份或 Code Mode start/settled 两份 records；approval interaction/events、result/failure 与 plugin-owned payload 不复制。
  • 影响 DSH application 与 Core 的 optional signal；CLI 省略 signal 时保持兼容。
