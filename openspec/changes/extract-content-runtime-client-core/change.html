Tina Change View · extract-content-runtime-client-core

让 daemon 成为外壳，让 runtime 成为共享能力

Client Core 统一拥有 worker、pool、内容读取与可靠提交；CLI 保留原有 daemon 协议，未来 local DSH Client Shell 可直接复用同一个 runtime owner。

Scope / Non-goals

  • 提取 worker、pool、read/export、Worktree execution 与 commit pipeline。
  • 保留 daemon command/socket、Session 文件、license 来源和 RPC wire shape。
  • Office、Typst、render、screenshot/lint、SVG 与 DSH tools 留给后续 Change。

Decisions

  • 同一 Client Core owner 暴露四项最小操作：read、export、execute-and-commit、close。
  • 交付方提供 worker entry、credential 与 license；Core 不读取 CLI 配置。
  • 图片外置属于 commit pipeline，不依赖 Blob/Asset file-transfer capability。

Risks / Impact

  • worker init 中的 credential/license 不得进入 RPC、结果、日志或错误 detail。
  • CLI worker build entry 必须继续进入自包含安装包。
  • 提交失败会 invalidate runtime，避免复用不确定 mutation。
