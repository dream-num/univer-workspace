Tina Change View

提取 Blob / Asset 文件传输能力

把协议恢复与本地文件安全移入 private Workspace Client Core，让 CLI 只保留 Client Shell，同时保持现有命令和可靠性语义。

Scope / Non-goals

  • 迁移 Blob、Asset 与其共用的 Node 文件安全。
  • 保留 CLI 命令、结果、错误、覆盖和恢复语义。
  • 不包含 Office、截图、Typst、SVG、remote FS 或 DSH app。

Decisions

  • 扩展一个 private Client Core package，不新建 transfer package。
  • 复用惰性 authenticated HTTP provider。
  • 保留具体 Node 文件实现；更新少量 imports 后删除旧 owner。

Risks / Impact

  • 依赖 `extract-space-node-client-core` 先完成。
  • tarball smoke 防止残留 workspace import。
  • 实现只落在 `univer-workspace`；规划暂留本仓库。
