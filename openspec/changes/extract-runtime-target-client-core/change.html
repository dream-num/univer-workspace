Tina Change View

提取 Runtime Target Client Core

把 target、Snapshot 与跨 Unit reference 的 Workspace 规则移入 private Client Core，同时让 CLI 继续拥有 Session、daemon、worker 与运行时生命周期。

Scope / Non-goals

只迁移 target identity、Worktree/Trunk source、Snapshot adapter 与 reference policy。daemon/runtime pool、Session、worker lifecycle、Asset bytes、execute/commit、Office 和 render 均留待既定后续 Changes。

Decisions

  • 扩展同一个 private packages/client-core。
  • plain-JSON target contract 不依赖 daemon types。
  • 保留两条 Snapshot 读取路径各自的错误合同。

Risks / Impact

主要风险是 prerequisite exports、错误码和 target payload 漂移。迁移既有 cases，并以 CLI daemon/worker、真实 tarball verify 与 smoke 固定兼容性。

Derived from proposal.md and design.md. Markdown sources are authoritative; this view is non-normative.
