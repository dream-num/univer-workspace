Tina Change View

提取 Office Exchange Client Core

Client Core 统一拥有 Office 格式策略、Workspace workflow 与 Node adapter；CLI 仅保留命令、daemon 适配和可安装 native binding 的交付责任。

Scope / Non-goals

只迁移 Office import/export、格式与 Unit 校验和 Node adapter。保持本机 path-based I/O；不加入 Typst、render、remote filesystem、artifact store 或新文件写入语义。

Decisions

  • 复用 Changes 3、5、6 的 Unit create、target 和 UnitData export。
  • Client Core 不依赖 Commander 或 daemon wire type。
  • CLI artifact 继续显式交付 native binding。

Risks / Impact

风险集中在格式校验顺序、conversion options、native dependency 外置和 bundle 自包含。现有 behavior、真实 XLSX round trip、package verify 与安装 smoke 共同锁定兼容性。
