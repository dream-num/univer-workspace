把 Blob/Asset 字节安全落在调用 Session 的 cwd

两种 download 先按当前 policy 拒绝 read-only，再用 rc.2 public LocalFileSystem constructor 证明 Host-local；E2B 即使没有 sandboxMode 也在零 path/ask/I/O 下失败。通过 identity 与 containment 才询问一次，body 重做三道 gate 后才调用 processPath。

Scope / Non-goals

  • Blob metadata、upload/download 与 Worktree Asset download。
  • 路径必须落在调用 Agent Session cwd；workspace-write 还受 policy root 约束。
  • 不支持 E2B、remote filesystem、inline bytes、Office、render、Jobs 或 Skills。

Decisions

  • read-only 在 provider 前 typed deny；non-local 在 path 前 typed deny，均不 ask。
  • 只正向接受 rc.2 public LocalFileSystem 与本地 sandbox subclass。
  • preflight 不留状态；body 重读 policy/identity/path 后才 processPath。

Risks / Impact

  • sandboxMode undefined 不能证明 local；public constructor gate 排除 E2B。
  • Core 的 node:fs 不经过 DSH text fence；approval 两侧三道 gate 关闭该绕过。
  • 取消撞上远端 unknown 时保留 public intent，停止后续 recovery。
  • force 仍需 approval，且完整写入后才原子替换。
  • 影响 DSH app 与 Client Core；Server、OpenAPI、CLI command 不变。
