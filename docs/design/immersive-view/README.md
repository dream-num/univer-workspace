# 资源沉浸视图

## 已实现的交互

- 所有资源统一通过 `/nodes/:nodeId?view=immersive` 进入；标准视图省略 `view`。
- 沉浸时不显示 Workspace 顶栏、侧栏、浮动退出按钮。资源自身的内容与编辑工具保持原样。
- 标准视图在分享按钮右侧提供小图标链接，悬停提示“进入沉浸视图 / Enter immersive view”。
  与页面操作放在同一行，位于 Workspace 全局设置之前，窄屏仍保留图标。
  使用同一 Lucide 图标库的四角展开图形，16px、1.75 描边、28px 点击区域，无边框，悬停显示浅底色。
- 普通点击在当前页进入并增加历史记录，Ctrl / Command 点击和中键沿用浏览器的新标签页行为。
- 浏览器后退回到进入前的页面；直接打开分享链接时，沿用浏览器自身的历史记录。
- 不绑定快捷键，不调用 Fullscreen API，不提供页面内退出控件。移动端可以使用浏览器返回。
- 未识别的视图值按标准视图处理；目录页面不进入沉浸视图。

## 分享

分享弹窗在“复制链接”旁提供一个“沉浸视图”复选框；勾选开启，取消则使用标准视图。
不额外提供选项标题或说明文字。选择只生成 URL，不修改当前页面或访问权限。
`.univer.html` 的分享与列表“复制链接”默认沉浸，其他类型默认标准；重新打开分享弹窗恢复默认值。
使用当前 `node.name` 的 `.univer.html` 后缀判断 Blob 文件的默认分享视图。
重命名去掉后缀后默认标准视图，仍可手动勾选沉浸。不扩展后端、HTTP 摘要或数据库。

## 实现边界

路由拥有 URL 状态和入口链接，WorkspaceLayout 只负责隐藏界面；
内容树结构和 Resource key 不随视图参数变化，因此编辑器、iframe 和协同连接不重建。
参数保留至登录返回地址，Unit canonical redirect 保留沉浸参数。

HTML 不安装按键监听或 iframe 按键桥接，使用原有 Renderer runtime。
StrictMode 重放时只由存活的 effect 设置 srcdoc，避免旧连接消息与新宿主不匹配。

HTML 离开保护豁免同一页面的视图切换，以及同一 HTML 入口的 search、hash 定位变更；
后者要求路径、所选 Node、Unit 和 Space 保持一致。切换这些身份仍执行既有保存保护。
入口同步与页面事件见 [Browser 集成](../html-views/browser-integration.md#app-入口定位)。
HTML 不显示独立的加载、保存或同步状态提示；加载失败、解析错误和运行时错误仍通过错误提示呈现。
所有资源的退出方式均由浏览器导航承担。
