# 模板解析与渲染

[返回 Univer HTML Views 总览](README.md)

阶段：已实现基于已加载 Engine 的同步挂载；真实协同联动仍待验证。

解析与渲染将 [HTML 模板](template-language.md) 挂载为可交互页面，通过
[Binding 引擎](binding-engine.md) 连接单元格，负责 DOM 更新、控件输入和资源释放。

## 解析与挂载

1. 解析 HTML，识别两个绑定属性，校验引用格式和控件类型；错误定位到元素与属性。
2. 将引用转换为 Unit ID 和 `{ sheetId, row, col }`。例如 `B7` 转为 `{ row: 6, col: 1 }`。
3. 宿主按 Unit ID 创建并加载 Engine，完成来源授权和 SDK 装配；渲染器连接各个目标元素。
4. 按 Engine 与坐标聚合同一单元格的 DOM 目标；订阅立即通知初始状态，之后持续更新。

[html-view-renderer](../../../packages/html-view-renderer/README.md) 接收解析结果、Document
和已加载的 Engine 映射，同步挂载并返回 `{ dispose }`。其 `mountCellBindings` 入口只接收
DOM 元素、Engine 和坐标。React 宿主负责来源加载、协同保存状态、路由离开前的 flush 与
Engine 释放；Renderer 只负责 DOM 生命周期。

## DOM 更新与输入

文本绑定更新元素的 `textContent`；空单元格显示空文本，公式格显示计算结果。
加载前保留模板占位文字。控件绑定更新 `value` 或 `checked`，只有用户输入触发写回，
订阅带来的 DOM 更新不会形成写回循环。

| 控件 | 提交事件 |
| --- | --- |
| 文本输入、`textarea`、单选 `select`、`input type="number"` | `change` |
| `input type="range"` | `input` 节流，`change` 提交最终值 |
| `input type="checkbox"` | `change` |

控件适配按模板声明完成类型转换，并检查 `min`、`max`、`step` 等约束。
数值输入为空或无效时保留为编辑草稿，不转换为零或写入 `NaN`；类型不兼容时显示错误。
目标可用且可写时才允许提交，Binding 引擎接收转换后的标量值。

## 编辑与异常处理

- **编辑草稿**：编辑期间保留本地输入，远端更新仍记录为最新数据；提交时写入草稿，
  取消编辑时恢复最新数据。已提交的值通过协同机制合并。
- **频繁写入**：滑块每 100 毫秒最多执行一次本地写入，等待期间只保留最新输入；
  `change` 跳过剩余等待并提交最终值。同一 Engine 与坐标共享节流。写入同步执行，
  不维护异步请求队列、版本号或重试状态机。
- **失败状态**：目标不可用或不可写时禁用控件。非法输入和被拒绝的本地写入显示错误，
  保留草稿，用户可重新编辑提交或按 Escape 取消；不增加重试按钮或自动重试。
- **协同状态**：本地写入成功不代表已保存。宿主订阅 SDK CollaborationStatus 并显示同步状态，
  站内路由离开前调用 flush；失败显示错误并停留当前页面。存在未同步状态时，关闭或刷新页面
  使用浏览器的离开提示。dispose 不自动保存，也不保证浏览器被强制结束时数据已经同步。
- **执行范围**：首版支持 HTML、CSS 和绑定属性，模板脚本及内联事件处理器不执行。
  页面脚本能力随全局 API 一起设计。

节流限制持续操作中的执行频率，适合滑块实时反馈；防抖等待操作停止一段时间后执行。
节流由渲染器的控件适配负责，Binding 引擎保持直接写入语义。

## 资源释放

Renderer 销毁时取消计时器和未提交的输入，移除 DOM 监听、取消单元格订阅并禁用控件。
它不释放 Engine。挂载中途失败执行同样的 DOM 清理。

宿主负责释放 Engine；产品 API 使用自身 AbortSignal。加载期间退出会销毁已创建的 Engine，
迟到的 SDK 加载结果不会重新挂载页面。一个来源加载失败即结束本次页面加载并释放其他来源，
不建立部分成功或自动恢复协议。
