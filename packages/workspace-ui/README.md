# Univer Workspace UI

Private Workspace UI primitives shared by Workspace Browser and the local DSH Harness.

This package owns the visual, focus, keyboard, portal, and accessibility behavior of the Workspace controls used by file management. Consumers compose these primitives or use the higher-level `@univerjs/univer-workspace-file-browser` package.

This package is internal to this repository and is not a public Univer SDK.
